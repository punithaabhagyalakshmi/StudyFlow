# StudyFlow OS

You are an expert Product Manager, Senior UI/UX Designer, Senior Full Stack Engineer, Database Architect, and AI Engineer.

Build a complete production-ready AI-powered web application called **StudyFlow AI**.

This is NOT a simple study planner. It is a premium AI Academic Operating System designed for students to organize, plan, study, revise, and achieve their academic goals.

The application should look like a modern SaaS product inspired by Notion, Linear, Apple, Vercel, and Arc Browser.
