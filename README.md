## 🌟 About

**StudyFlow AI** is an AI-powered academic productivity platform built to help students manage every aspect of their learning journey.

Instead of switching between multiple apps for planning, note-taking, flashcards, calendars, focus sessions, and AI assistance, StudyFlow AI combines everything into one seamless experience.

Whether you're preparing for exams, managing assignments, or trying to build consistent study habits, StudyFlow AI is designed to help you learn smarter—not harder.

# ⚙️ Installation

## Clone the Repository

```bash
git clone https://github.com/punithaabhagyalakshmi/StudyFlow.git
```

## Go to the Project Folder

```bash
cd StudyFlow
```

## Install Dependencies

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```

Visit:

```
http://localhost:3000
```
